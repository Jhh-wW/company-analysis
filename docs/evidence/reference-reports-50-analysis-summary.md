## 표본과 무결성

25개 회사마다 공식 문서 1개와 외부 분석 1개를 짝지어 총 50개를 검토했다.

|---|---:|
| 국내 / 해외 회사 | 20 / 5 |
| 대형 / 비대형 회사 | 5 / 20 |
| PDF / HTML | 47 / 3 |
| PDF 전체 페이지 | 4,367 |
| 추출 본문 | 약 680만 자 |
| 실제 주요 제목 | 552 |
| 빈 파일·중복 파일·짝 누락 | 0 |

공식 문서는 연차·법정 보고서와 IR을 중심으로, 외부 문서는 투자·산업 분석을 중심으로
선정했다. 한 회사의 공식·외부 문서를 한 쌍으로 보아 공통점과 역할 차이를 함께
비교했다.

## 집계 기준

- **내용 등장**: 독립 제목이 없어도 본문에 실질 설명이 있으면 포함
- **독립 제목**: 해당 내용을 큰 제목이나 소제목으로 따로 강조
- **양쪽 포함**: 같은 회사의 공식 문서와 외부 분석에 모두 등장

등장률은 정보의 필요성을, 독립 제목률은 별도 장으로 둘 관행을 보는 보조 지표다.
둘 중 하나만으로 정본 목차를 결정하지 않았다.

## 정본 설계에 반영한 결론

1. 공식 문서를 사실의 출발점으로 삼고 외부 분석은 실적 원인·위험·경쟁력의 과장
   여부를 교차 확인하는 데 쓴다.
2. 제품·서비스는 50개 모두에 등장하므로 다른 설명 안에 묻히지 않게 전용 장으로 둔다.
3. 최근 실적은 숫자 나열이 아니라 제품·지역·가격·비용이 만든 변화 원인을 설명한다.
4. 완료·진행 중인 실행과 미래 계획·목표를 시간 상태로 분리한다.
5. 파트너·유통·IP는 중요하지만 회사별 관련성에 따라 독립 장 또는 관련 장의 근거로
   다룬다.
6. 가치평가와 단순 급여·근속 표는 회사 이해를 위한 핵심 본문에서 제외한다.
7. 핵심 경쟁력은 새 자료나 일반론을 추가하는 장이 아니라 앞선 공식 근거를 종합하는
   장으로 설계한다.

이 결론은 현재 [출력물 기준](../출력물%20기준/README.md)의 목차와 공통 규칙을 설명하는
연구 근거다. 정본 계약 자체는 아니며, 충돌할 때는 출력물 기준과 런타임 출고 계약이
우선한다.

## 한계

- 공식 표본은 연차·법정 보고서와 IR 비중이 높아 채용·문화 정보가 적게 잡혔을 수 있다.
- 외부 표본은 투자 분석 비중이 높아 실적·자본 배분·가치평가가 크게 잡혔을 수 있다.
- 후원·의뢰형 외부 문서 4쌍을 제외한 21쌍 재계산에서도 여섯 핵심 항목은 100%,
  사업·수익 구조는 97.6%로 핵심 순위가 유지됐다.
- 공통 코딩 기준은 적용했지만 복수 코더의 독립 재코딩 실험은 하지 않았다.
- 따라서 이 결과는 목차 결정을 위한 1차 근거이지 보편적 중요도의 절대 기준이 아니다.
