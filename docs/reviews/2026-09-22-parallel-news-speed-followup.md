독립 검토에서 기존 예산 시험의 요청이 같은 호스트에 몰려 실제 동시 실행을 증명하지 못한다는 빈틈을 발견했다. 별도 Astra 작업이 서로 다른 호스트 3곳의 본문 완료 순서를 뒤집는 회귀 시험 3건을 추가했고 모두 통과했다. 실제 최대 동시 콜백 3개, 분석 중 본문 요청 0개, 마지막 분석 후 추가 본문 요청 0개와 원문·해시·기사 순서 보존을 확인했다. 제품의 수집 상한이나 호출 횟수는 늘리지 않았다.

Claude Fable은 최초 본문 검수부터 기존 JSON 출력 규칙을 전달하도록 수정했다. 같은 답변 대본 15종의 검증 결과와 캐시 경계·재시도 상한·정산 경로를 보존하는 시험을 포함해 관련 시험 170건을 통과했다. 이는 실제 공급자의 응답 시간과 비용 절감을 확정한 결과가 아니며, 총괄의 전체 composer 회귀 결과는 별도로 기록한다.

## 공식 약칭 후속 완료

공식 원문 조사 뒤 같은 Astra 터미널에 작업을 다시 배정하려던 시도는 시작 준비 시간 초과로 실패했다. 이후 사용자가 해당 터미널에서 직접 후속 작업을 지시했고, 총괄은 PDF 담당과 파일 경계를 확인하여 뉴스 전용 연결을 승인했다. 사용자 소유로 전환한 터미널은 종료하지 않았다.

후속 구현은 공식 원문에 전체 법인명과 명시된 약칭만 추출하여 뉴스 분기에 전달한다. 기존 회사·문서·원문 해시·위치·공식 신원 증명이 맞아야 하고, 홈페이지 신원 판정에는 되돌려 넣지 않는다. 신규 58건을 포함한 관련 회귀 **142건 통과, 7.02초**를 확인했다. 실제 공개 정의와 시험용 typed 영수증을 구별하고, 다른 회사·자회사·부정문·없는 인용 및 등록번호 불일치 반례를 검사했다. 총괄은 helper·연결 코드·긍정 및 거절 시험과 기존 shared 결속 검증을 읽어 검토했다.

추출 자체의 추가 API·AI 호출은 없다. 새 약칭 검색은 기존 상한 안에서 최대 1회 늘 수 있고 유료 분석 상한은 그대로다. 운영 수집 원본에 해당 정의가 실제 들어오는지는 아직 새 실행에서 확인하지 못했으므로 뤼튼 기사 0건이 완전히 해결됐다고 결론내리지 않는다.

이 시점 PDF 담당의 1차 통합 소스는 `3d4b50ea`이며, 출처·미감사 표시·부록 고아 행과 도식 설명의 2차 보완은 별도 팀이 계속 담당한다. 완료된 최초 검수 `39d64907`과 뉴스 `dd0945b6` 및 공식 약칭 후속 커밋을 최종 통합에 포함하도록 전달한다. 전체 작업 완료·운영 배포·시간 절반 달성은 아직 확인되지 않았다.
