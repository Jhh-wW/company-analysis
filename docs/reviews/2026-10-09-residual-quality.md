# 수익모델과 현재 사업 과제의 근거 검수

## 실제 보고서에서 추가로 확인한 문제

자동 FULL 판정을 받은 보고서를 원문과 대조하니, 2장의 유일한 수익모델 문장이 수익 계정의 포함·제외 정의였다. 문장 자체는 참이어도 고객에게 무엇을 제공하여 돈을 버는지 설명하지 못했다. 또 5장에는 개발 과제명과 양산 예정만 있는 인용을 근거로 `개발이 이루어지고 있다`고 쓴 문장이 남았다. 이 때문에 자동 FULL과 PDF 생성 성공을 최종 품질 합격으로 인정하지 않았다.

- 수집·재분류·최종 검수에서 계정 정의만으로 수익모델 칸을 채우지 못하게 한다. 혼합 원문은 보존하고 그 칸의 채점 범위만 제한한다. 실제 판매·구독·기술사용권·은행 대출·보험·신탁 거래와 다른 의미칸은 유지한다. 생략된 표제의 각주는 복수의 계정명과 정의 문법이 함께 있을 때만 제한한다.
- 명사형 현재 수행 표현도 같은 활동·대상·시점의 자기 인용을 요구한다. 개발 완료, 미래 양산, 특허 진행, 개발 중단은 현재 개발의 근거가 아니다. 현재 개발을 직접 밝힌 원문과 과제 설명만 있는 문장은 유지한다.
- 검수 모델이 대상의 조사를 생략해 양쪽에 없는 표현을 만들면 정상 문장도 탈락했다. 대상·역할값을 후보와 인용에 공통으로 존재하는 연속 표현으로 제출하도록 안내한다. 주체·사업부·관계 검사 코드는 완화하지 않는다.

수집 버전은 `evidence_collection/3.14`로 올린다. 원문 파서 형식은 바뀌지 않아 파서 버전은 유지한다. 배포 revision이 생성 cache namespace에 포함되며, 기존 재분류 cache도 현재 검증기로 다시 검사한다.

## 문제와 수정

현재 대응 문장이 검수에서 탈락해도 FULL 보충 작성에는 빠진 의미칸과 허용 근거만 전달됐다. 보충 작성자가 원문의 미래 목표를 다시 현재 활동으로 적으면 같은 이유로 탈락할 수 있었다. 실제 시점 검사 실패를 후보 지문과 자기 인용으로 재확인하고, 해당 원문·실패 후보를 기존 보충 요청에 자료로 전달한다. 새 문장은 기존 검수를 다시 통과해야 한다. 현재 활동이 없으면 빈 칸을 유지한다.

산업 인용에서는 현재 제약과 대응 가능성을 같은 문장에 적으면 대응의 ‘할 수 있다’ 때문에 현재 문제도 미래 가능성으로 제외될 수 있었다. 같은 문제에 명시된 현재 상태와 뒤의 별도 대응절이 확인될 때만 두 범위를 구분한다. 쉼표로 나열한 미래 문제나 예방 설명을 현재 문제로 승인하지 않는다. 지역·사업 적용·정확한 자기 인용 검사는 유지한다.

## 범위와 한계

- 현재 대응 안내는 누락된 5장 대응 칸에만 붙는다. 후보·지원쌍·원문 지문이 다르면 사용할 수 없다. 원문을 자르거나 정답 문장을 자동 생성하지 않는다.
- 추가 AI 호출과 품질 하한 변경은 없다. 산업 검사 의미가 바뀌므로 산업 캐시 버전을 분리한다.
- 보존 응답의 산업 미제안은 모델 단계의 결과다. 새로 확인한 검증기 과차단이 당시 모델 미제안의 원인이었다고 단정하지 않는다.
- 무료 재생은 기존 원문과 코드를 대조하는 검사다. 새 실제 보고서·공개 내용·PDF의 품질 합격은 별도로 확인해야 한다.

## 검증 대상

전체 회귀에서 `소송 진행 중.` 뒤 별도 문장의 `공사 중단`을 앞 활동의 상태로 잘못 읽는 문제가 드러났다. 명사형 `중.`도 문장의 끝으로 처리한다. 기존 소송 시험의 기대값은 유지하고 다른 문장의 중단·진행 상태를 가져오지 않는 반례를 추가했다.

역할 안내 138자 추가로 바뀐 프롬프트 시험 지문은 별도로 갱신한다. 안내만 메모리에서 되돌려 본문·도식 전체 바이트와 이전 지문이 복원되는 것을 독립 검수했으며, 근거·번호·스키마·캐시 경계는 유지한다.

현재 문제와 별도 대응의 양성 사례, 미래·조건·예방·부정·열거의 음성 사례, 다른 장·후보·지원쌍·원문 지문 대여, 입력 상한 및 기존 보충 경로를 검증한다. 실제 보고서 검증에서는 FULL/부분 계약을 구분하고 산업 문제를 회사의 확정 피해로 바꾸지 않는지 확인한다.

추가 수정의 집중 검사와 독립 검수는 계정 정의의 정중한 활용·금액 포함·생략 표제, 실제 금융업 수익, 혼합 원문, 현재 수동형의 완료·중단·부정·다른 대상 반례를 다룬다. 실제 원응답의 계정 정의와 명사형 현재 개발이 새 경계에서 거부되는지도 무료 재생한다. 근거 표현만 바로잡은 가상 검수 항목은 정상 문장 세 개를 기존 기준으로 통과시켰지만, 이는 실제 모델이 새 안내를 따랐다는 증거와 구분한다.
