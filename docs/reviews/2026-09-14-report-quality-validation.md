# 실제 보고서 품질 확인 기록

사용자가 승인한 배포 후 생성·품질 검사·재수정의 API 비용 한도는 누적 20,000원이다. 이번 검사에 사용한 실행의 실제 비용과 미확정 예약액을 합산한다. 실패 실행도 포함하고, 한도를 넘겨 새 유료 실행을 시작하지 않는다.

## 합격 기준

| 확인 대상 | 확인할 내용 |
| --- | --- |
| 회사 선택 | SK·키움의 법인 신원이 정확하며 주소·동명 회사 혼동이 없음. SK AX 검색 결과는 확인된 법인과 사업 조직의 관계를 설명함 |
| 자료 활용 | SK처럼 자료가 충분하면 주요 사업·수익 구조·제품과 서비스·실적·변경 사항·위험이 실질 내용으로 남음 |
| 자료 부족 | 일부 수집 실패·잘림 또는 자료가 적을 때 확보한 내용과 미확인 범위가 함께 나옴 |
| 뉴스 | 키움의 관련 뉴스가 본문 또는 보도표에 적절히 사용되며, 제외되는 뉴스는 실제 검증 사유를 추적할 수 있음 |
| 사실 정확성 | 대표 수치·단위·기간·회사 주체·사업 관계를 인용 원문과 대조함. 타사 사실이나 미실행 계획을 실적으로 단정하지 않음 |
| 출처 | 본문·표·뉴스의 인용이 실제 원문과 연결되고 관련 없는 출처로 사실을 포장하지 않음 |
| 읽기 품질 | 반복 안내가 핵심 내용을 밀어내지 않고, 요약과 본문이 서로 맞으며 독자가 회사의 사업을 이해할 수 있음 |
| PDF | 실제 파일이 열리고 본문·표·출처가 잘리지 않으며 빈 페이지·겹침·깨진 한글이 없음 |
| 운영 | 배포한 커밋이 health 응답과 같고 readiness·저장·웹 조회·PDF 다운로드가 정상임 |

보고서 생성 성공이나 문장 수만으로 합격하지 않는다. 검수 탈락 문장을 강제로 살리거나 대상 회사의 사실을 지어내는 방법으로 점수를 높이지 않는다.

## 실행 기록

아직 배포 후 유료 생성은 시작하지 않았다. 실행별 결과·비용·발견한 결함·수정 커밋·재검사 결과는 실제 실행 후 기록한다.
