## 실측 준비의 제한

현재 프로세스와 Windows 사용자·컴퓨터 환경에 DART·Anthropic·뉴스 API 설정이 있는지 값 없이 존재 여부만 확인했으나 모두 없었다. Orca의 이전 대화 검색도 사용자 설정에서 꺼져 있어 검색하지 않았다. 이전에 사용한 설정 파일 위치를 사용자에게 요청한 상태다. 키 내용은 요청하지 않는다. 고정 소스와 설정이 준비되면 새 실행에서 기사 사용, 보고서 품질, 총 시간, 실제 사용량·원가를 확인해야 한다.
