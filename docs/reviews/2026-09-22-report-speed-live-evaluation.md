# 보고서 속도·비용 실제 비교 시험

## 비교 조건

대표 회사는 현대글로비스(주), DART 법인 번호는 `00360595`다. 9월 22일 DART 기업목록과 기업개황으로 확인했다. 기존 9월 13일 보고서의 721.61원은 참고값이며 이번 기준군의 비용으로 대신 쓰지 않는다.

| 조건 | 순차 기준군 | 병렬 실험군 |
|---|---:|---:|
| 작성 동시 상한 | 1 | 3 |
| 공급자 전체 동시 상한 | 1 | 5 |
| 뉴스 본문 수집 동시 상한 | 1 | 2 |
| 검수 지침 캐시 | 꺼짐 | 꺼짐 |
| 엔진·출고 모드 | v2·FULL | v2·FULL |
| 뉴스 수집 | 켜짐 | 켜짐 |

두 실행은 같은 커밋과 회사 입력을 사용하고 별도의 로컬 평가 DB에 저장한다. 현재 런처는 비교 수집 스위치 `PARALLEL_COLLECT`를 전달하지 않아 양쪽 모두 기존 기본값인 꺼짐을 사용한다. 운영 서버 설정·성능과 같다고 주장하지 않는다.

완전한 수집 자료 재생 기능은 기존 HTTP 평가기에 없다. 따라서 회사 입력만 같다는 이유로 같은 자료라고 간주하지 않고 공시·뉴스·작성 입력의 일치 여부를 확인한다. 자료가 다르거나 작성 입력을 대조할 수 없으면 전체 시간 반감의 인과 검증은 미확인으로 남긴다.

## 준비 과정에서 수정한 문제

성능시험 실행기가 부모의 동시 실행 설정을 제거하여 순차·병렬을 구분할 수 없었다. `WriterMaxParallelCalls`, `ProviderMaxConcurrentCalls`, `NewsBodyFetchConcurrency`, `EnableReviewPromptCache` 인자로 설정을 명시하고 자식 프로세스와 비밀을 제외한 설정 영수증에 똑같이 전달하도록 보강했다. 범위 밖 값은 서버를 띄우기 전에 거절한다.

평가기에서는 네 설정의 누락·잘못된 값·회차 도중 변경을 검증한다. 과거 영수증에 없던 값은 추정하지 않고 미관측으로 둔다. 실제 PowerShell 자식 환경과 평가기를 포함한 관련 시험 98개가 통과했다.

## 판정과 비용 기록

서버 전체 생성 시간, 작성 시간, 공식 PDF 완료 여부, 호출 수, 모델별 실제 사용 토큰, 캐시 저장·읽기 토큰, 실패 비용과 미정산 여부를 함께 확인한다. 텍스트 길이와 자동 통과만으로 품질 동등을 판단하지 않고 숫자·출처·누락·뉴스 반영·PDF 표시를 검토한다.

첫 순차·병렬 각 한 건만 시작한다. 기존 체크포인트와 세션을 보존하며 접수 결과가 불명확하면 새 유료 요청을 보내지 않는다. 런처 기본값인 건당 예상비용 4,000원·일일 10,000원은 사전 예약 기준이며 공급자 청구 총액의 강제 상한이 아니다.

## 운영 적용 조건

실제 비교 결과가 시간·비용·품질 기준을 충족한 뒤 회귀 검사와 컨테이너 검사를 완료하고, 진행 중 운영 조사를 확인한 후 적용한다. `main` 푸시는 Render 배포를 바로 유발하므로 시험 준비 커밋과 운영 반영을 구분한다. 현재 운영 적용은 완료되지 않았다.
