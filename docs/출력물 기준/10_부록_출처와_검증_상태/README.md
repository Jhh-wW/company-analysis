# 부록. 출처와 검증 상태

- 문서 버전: v1.1 (2026-09-06) · 청중: 이 저장소의 구현·검증 담당자
- 프로그램 계약 정본: [`런타임 출고 계약`](../90_공통_규칙/런타임_출고_계약.md)

## 이 장의 목적

본문의 모든 사실이 어느 원문에서 왔는지 독자가 직접 추적할 수 있게 한다. 자료의 발행 주체·시점·위치와 사실 상태·검증 상태를 분리해 보여줘 `실제`, `잠정`, `계획`, `추정`, `검증 완료·부족`을 서로 섞지 않는다.

이 장은 제작 과정 설명이 아니다. 조사 방법, 사용한 AI·에이전트, 50개 레퍼런스 분석, 내부 검수 절차는 완성 보고서에 넣지 않는다.

## 이 장이 답해야 하는 질문

1. 본문의 `[번호]`가 정확히 어떤 원문 문서·웹페이지를 가리키는가?
2. 누가 언제 발행했고, 어느 페이지·표·섹션에 근거가 있는가?
3. 허용된 공식 자료 유형은 무엇이며 `fact_status`와 `verification_status`는 각각 무엇인가?
4. 링크를 눌러 독자가 원문을 확인할 수 있는가?
5. 서로 다른 자료가 충돌하거나 해석에 한계가 있을 때 그 상태가 표시됐는가?

## 한 줄 요약

부록은 본문에서 실제로 쓴 원문만 번호·발행처·날짜·위치·상태와 함께 한 번씩 싣는다.
공식 원문이 정본이고, 언론 보도는 스위치가 켜진 실행에서 실제 인용했을 때만 `언론 ·
외부 보도`로 같은 표에 남는다.
