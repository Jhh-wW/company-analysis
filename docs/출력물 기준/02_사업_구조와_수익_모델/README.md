# 2. 사업 구조와 수익 모델 출력 기준

## 목적

누가 무엇에 돈을 내고, 회사가 어떤 제품·서비스와 채널을 통해 매출과 이익을 만드는지 설명한다. 단순 매출표가 아니라 고객·제공 가치·과금 방식·확장 경로가 연결된 사업 구조를 보여준다.

> 내부 설계 근거: 사업·수익 구조는 50개 중 49개, 고객·시장은 50개 모두에 등장했다. 다만 고객·시장의 독립 제목률은 낮아 제품·실적 속에 묻히기 쉬웠다. 따라서 `핵심 고객과 우선시장`을 필수 소절로 둔다. 이 설명은 완성 보고서에 출력하지 않는다.

## 이 장이 답할 질문

- 실제 구매자·사용자·수혜자는 누구이며 서로 같은가?
- 고객은 어떤 문제 해결이나 가치를 위해 돈을 내는가?
- 제품·서비스별 과금 방식과 주요 수익 경로는 무엇인가?
- 한 번의 판매와 반복 구매·구독·서비스·후속 상품은 각각 어떤 공식 수익 경로로 분류되는가?
- 회사가 우선하는 고객·지역·산업·용도·채널은 어디이며 근거는 무엇인가?

## 필수 입력자료 우선순위

1. 최신 사업보고서·연차보고서의 사업 내용, 매출 유형, 고객·지역 정보
2. 최신 공식 IR의 사업부·제품·지역·채널별 매출 구성과 경영진 설명
3. 공식 제품·서비스·가격·고객사례·유통 페이지
4. 정부·규제기관의 허용된 공식 원문
5. 외부 기업분석은 수익 원인과 고객 구조를 내부에서 교차검증할 때만 사용하며 공개 `FactRecord`·출처로 승격하지 않음

매출 분류의 정의와 연결 범위가 다른 자료는 합산하지 않는다. 가장 최신의 완전한 회계기간을 기준으로 삼고, 잠정치는 상태를 표시한다.

## 조사 절차

1. 모든 사업부·제품·서비스와 매출 항목을 긴 목록으로 수집한다.
2. 각 항목을 `고객 → 제공 가치 → 제품·서비스 → 과금 주체·방식 → 반복·확장 경로`로 연결한다.
3. 구매자·사용자·수혜자가 다르면 분리하고, 판매·유통을 돕는 파트너는 고객에서 제외한다.
4. 전체 매출을 설명하는 핵심 수익 경로 2~4개를 고른다.
5. 공식 분류가 완전하고 서로 겹치지 않을 때만 매출 구성을 계산한다.
6. `핵심 고객과 우선시장` 후보를 최대 3개 고객군과 최대 4개 시장군으로 압축한다.
7. 시장별 공식 전략과 실제 투자·출시·유통·매출 변화가 함께 확인되는지 검증한다.
8. 근거에 따라 시장을 `핵심·성장·진입`으로 분류한다. 전용 제품·조직·파트너가 확인될 때만 `현지화`를 병기한다.
9. 이 장이 소유하지 않는 전사 실적 변화는 4장, 현재 문제 수치는 5장으로 넘긴다.

매출이 한 번 발생했다는 사실만으로 해당 국가·산업을 `성장시장`으로 분류하지 않는다. `성장`은 두 시점 이상의 확대 신호 또는 공식 투자·제품·채널 확대가 함께 확인될 때만 사용하고, 근거가 부족하면 `매출 확인·시험·MOU·진입 계획`처럼 관찰된 상태만 적는다.

## 포함 기준

- 전사 매출의 대부분을 설명하거나 회사가 공식적으로 핵심이라 밝힌 수익 경로
- 고객이 실제로 지불하는 대상과 과금 방식
- 반복 매출·교차판매·후속 서비스 등 수익 확장 구조
- 최대 3개의 핵심 고객군과 역할 구분
- 공식 전략과 실제 실행 근거가 함께 있는 우선시장
- 수익 구조 이해에 직접 필요한 매출 구성비 1세트

## 제외 기준

- 제품 이름과 매출 숫자만 나열한 표
- 고객 근거가 없는 연령·취향·생활방식 페르소나
- 공개되지 않은 고객사 이름 추정
- 유통사·플랫폼·공연사·공급사를 최종 고객으로 오인한 설명
- 우선순위 없이 국가·산업을 길게 나열한 시장 목록
- 총매출·영업이익률 등 4장이 소유하는 전사 실적의 반복
- 제품별 최근 실행 근거 등 3장이 소유하는 사실의 반복
- 직무별 업무·KPI·개인별 지원전략. 이는 서비스 범위 밖이다.

## 출력 필드/형식

### 사업 구조

1. `사업 모델 한 문장`: 고객·가치·수익 경로를 한 문장으로 요약
2. `가치와 수익의 흐름`: `핵심 자산 → 제품·서비스 → 고객 행동/과금 → 반복·확장 수익`
3. `수익 구성`: 정의가 완전할 때만 하나의 차트 또는 표로 출력
4. `핵심 해석`: 어떤 수익축이 중심이고 서로 어떻게 연결되는지 1~2문장

### 핵심 고객과 우선시장

고객 표:

`대상 | 역할(구매자·사용자·수혜자) | 제공 가치 | 주요 수익 경로`

시장 표:

`단계(핵심·성장·진입·현지화) | 우선시장 | 판단 근거 | 사업적 역할`

- 고객은 최대 3개, 시장은 최대 4개로 제한한다.
- 공통 기준일은 소절 제목 또는 표 주석에 한 번만 쓴다. 모든 행에 같은 기준일을 반복하지 않는다.
- 지역 차이가 중요하지 않으면 `우선시장`을 산업·용도·판매 채널로 바꾼다.

## 문장 작성법

- `무엇을 판다`보다 `누가 어떤 가치에 왜 지불한다`를 먼저 쓴다.
- 매출 항목은 회계 명칭을 그대로 나열하지 말고 실제 고객 행동과 연결한다.
- `핵심 시장`은 규모·매출 기반, `성장 시장`은 확장 속도와 투자, `진입 시장`은 초기 실행, `현지화`는 전용 운영체계로 설명한다.
- 시장의 방향을 말할 때는 공식 전략과 실제 실행 근거를 함께 붙인다.
- 수익성 원인을 공개 자료로 확인할 수 없으면 매출 규모만으로 `고수익`이라고 쓰지 않는다.
- `영향·기여·흡수·개선` 같은 수익성 인과는 회사·공시·규제기관 공식 원문이 직접 설명한 범위에서만 쓰고 주체를 밝힌다. 외부 분석은 과장 여부를 내부에서 점검하는 보조자료일 뿐 공개 `FactRecord`·출처가 될 수 없다. 작성자의 가설은 `확인 변수·효과 미확인`으로 낮추거나 삭제한다.
- 권장형: `[고객]은 [제품·서비스]의 [역할]이며 [가치]에 지불한다. 회사는 [공식 전략+실행 근거]에 따라 [시장]을 [단계] 시장으로 둔다.`

## 시각화 사용 조건

- 수익 경로가 3개 이상이고 서로 연결될 때만 흐름도를 쓴다.
- 공식 매출 분류가 완전하고 합계가 일치할 때만 구성비 차트 하나를 쓴다.
- 흐름도는 관계를, 구성비 차트는 규모를 보여줄 때 둘을 함께 쓸 수 있다. 같은 숫자를 두 시각물에 반복하지 않는다.
- 고객과 시장은 역할 비교가 3개 이상일 때 표가 문장보다 낫다.
- 한 수익원만 있는 회사는 흐름도 대신 한 문장과 짧은 표를 사용한다.

## 업종별 변형

- 제조: 완제품·부품·소모품·유지보수, 직접판매·대리점, OEM/ODM 구조
- 플랫폼: 이용자와 광고주·판매자 등 지불 고객을 분리하고 거래·광고·구독 과금 표시
- SaaS: 좌석·사용량·구독·구축·유지보수와 갱신 구조
- 금융: 예대마진·수수료·운용수익과 자금 제공자·차입자·가입자 구분
- 바이오: 연구개발·기술이전·마일스톤·로열티·직접판매의 단계별 구조
- 콘텐츠·IP: 콘텐츠 판매·공연·광고·상품·라이선스·멤버십 연결
- 유통: 상품 매출·가맹 수수료·물류·광고·온라인 중개와 점포/채널 역할
- B2B 고객사가 비공개인 업종: 회사명을 추정하지 않고 산업군·업무 기능·구매 역할로 표시

## 실패 시 처리

- 사업부별 매출이 공개되지 않으면 비율을 추정하지 않고 확인된 수익 경로만 설명한다.
- 고객과 사용자가 구분되지 않으면 공식 이용 구조까지만 쓰고 임의 페르소나를 만들지 않는다.
- 시장 우선순위 근거가 약하면 `핵심·성장·진입` 분류를 붙이지 않고 확인된 영업 지역만 짧게 적는다.
- 제품·지역 분류가 자료마다 다르면 가장 최신 공식 정의를 사용하고 비교 불가능한 수치를 합치지 않는다.
- 파트너인지 고객인지 불명확하면 7장에서 관계를 다루고 이 장에서는 제외한다.
- 검증된 `revenue_model` 또는 `customer_market` 중 하나라도 없으면 2장 필수 계약이 성립하지 않으므로 빈 장·일반론을 공개하지 않고 보고서 전체를 `GATE_STOPPED`로 끝낸다. 공개하는 모든 `customer_market`에는 `market_priority`를 저장한다.

## 출고 전 체크리스트

- [ ] 구매자·사용자·수혜자를 필요한 경우 구분했는가?
- [ ] 고객의 지불 이유와 회사의 과금 방식이 연결되는가?
- [ ] 핵심 수익 경로 2~4개가 전사 구조를 설명하는가?
- [ ] 매출 구성의 정의·기간·범위·합계가 일치하는가?
- [ ] 고객은 최대 3개, 시장은 최대 4개인가?
- [ ] 시장 단계에 공식 전략과 실제 실행 근거가 모두 있는가?
- [ ] 단순 매출 발생을 성장시장으로 승격하지 않았는가?
- [ ] 수익성 인과가 출처가 직접 설명한 범위를 넘지 않는가?
- [ ] 파트너를 최종 고객으로 잘못 분류하지 않았는가?
- [ ] 3·4·5·7장 소유 사실을 반복하지 않았는가?
- [ ] 같은 기준일을 행마다 반복하지 않았는가?
- [ ] 직무별 업무·KPI·맞춤 지원전략을 넣지 않았는가?

## 짧은 범용 예시

> 기업 고객은 장비를 구매한 뒤 유지보수 계약을 갱신한다. 공식 매출 분류에서 장비 판매는 초기 매출, 부품·점검 계약은 반복 수익 경로로 구분된다.

실제 출력에서는 고객군·과금 방식·우선시장을 회사 공식 자료로 구체화한다.
