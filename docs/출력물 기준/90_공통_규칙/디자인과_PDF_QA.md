# 디자인과 PDF QA

- 문서 버전: v1.2 (2026-09-06) · 청중: 이 저장소의 조판·검증 담당자
- 프로그램 계약 정본: [`런타임 출고 계약`](./런타임_출고_계약.md)

## 목표

모든 회사 보고서를 같은 제품이 만든 공식 문서처럼 보이게 한다. 디자인은 정보를 돋보이게 해야 하며, 장식·색상·복잡한 도표 때문에 조사 품질이나 제작 시간이 흔들리면 안 된다.

기준은 현재 제품 결과 화면의 `흑백 팔레트·Freesentation·큰 여백·가는 선·간결한 표`와 기준 산출물의 A4 편집 방식을 따른다. 특정 회사의 브랜드 색이나 예외 레이아웃을 공통 규칙으로 하드코딩하지 않는다.

PDF는 사용자 다운로드 정본이다. 구조화된 내용은 공개 웹·Notion과 같아야 하며, 어느 출력도 별도의 활용 질문·지원 조언·구형 섹션을 추가할 수 없다. 필수 자동검사 전 항목 통과 전에는 어느 채널도 공개 정본이 아니다. 세부 런타임 조건은 [`런타임 출고 계약`](./런타임_출고_계약.md)을 따른다.
