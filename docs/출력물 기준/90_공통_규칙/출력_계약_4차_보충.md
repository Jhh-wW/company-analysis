# 4차 출력 계약 보충

- 기준일: 2026-09-23
- 적용 범위: 이번 수정 코드가 새로 만드는 v2 보고서와 공개 표시 자료
- 상위 계약: [런타임 출고 계약](런타임_출고_계약.md)

이 문서는 이번 변경으로 달라진 출력·관측·저장 호환 경계만 보충한다. 기존 FULL 필수 장, 품질 하한, 근거 부족에 따른 부분보고서 경로와 출고 판정을 새로 정의하지 않는다. 구현 계약의 기록이며 실제 회사의 유료 실측 통과나 배포 완료를 뜻하지 않는다.

## 공개 전 사실 결속 선택과 부족 안내

본문 검수 뒤 요약·최종 봉인 전에 공개 산문과 실제 `FactRecord`의 결속을 정본에서 확인한다. 장 소유권·문장·근거 결속이 맞는 문장만 남기며, 결속되지 않은 문장과 중복 문장의 제외 사유를 진단에 보존한다. 보도 표시 접두사와 정해진 문체 정규화를 고려하되, 단어가 일부 겹친다는 이유로 다른 주체·대상·조건·시점의 사실을 같은 것으로 승인하지 않는다. 해석 표지도 근거 결속을 대신하지 않는다.

이 선택으로 해당 장의 본문 문장이 모두 제외되면 정본 부족 안내를 남기고 기존 최종 조정·품질 판정을 적용한다. 화면에서만 문장을 지워 요약·저장 정본과 어긋나게 만들거나, 새 사실을 넣어 빈 장을 채우지 않는다. FULL의 결속 실패·내용 부족을 부분보고서 안내로 바꿔 통과시키는 규칙은 아니다.

## 검증된 본문을 재사용하는 요약

신규 v2의 엄격 경로와 부분보고서 경로 모두 공개 전 사실 선택을 마친 본문 `FactRecord`를 요약 후보로 사용한다. 후보 문장을 글자 변경 없이 고르고 `verified_fact_reuse`로 결속한다. 제외된 초안, 근거 없는 해석, 본문에 없는 사실을 요약에 남기지 않는다. 요약 전용 AI·Reviewer 호출 수는 0이며 기존 최소 개수와 최종 게이트는 유지한다. 상세 형식은 [핵심 요약 기준](../00_핵심_요약/README.md)을 따른다.

## 선택 9장도 관측하는 품질 자료

품질 관측의 기존 필수 1~8장 집계와 별도로, 실제 존재하는 9장 `competitive_position`은 버전이 있는 `optional_sections` 확장에 문장 관측과 평가를 남긴다. 선택 장이라는 이유로 공개 안전 검사에서 빠지지 않으며, 일반 회계정책이나 근거 없는 우위 문장을 차별점으로 채택하지 않는다. 9장이 없는 구형 관측 자료에 검사를 수행한 것처럼 새 통과 결과를 채워 넣지 않는다.

여기서 `optional`은 품질 관측 자료의 확장 구분이다. FULL에서 9장이 필수라는 기존 의미 계약을 선택 사항으로 낮추거나 필수 1~8장 하한 계산을 바꾸지 않는다. 저장·재조회 때 해당 관측 버전과 무결성을 함께 검증한다.

## 새 표시 제목과 선택 표시 필드

신규 4장의 표시 제목은 `주요 변화와 실적`이다. 내부 ID `past_changes`와 [4장 기준 문서](../04_3개년_주요_변화와_실행/README.md)의 기존 폴더명은 유지한다. 제목 변경으로 사건의 시간 상태나 실제 근거의 비교 기간을 바꾸지 않는다.

공개 표시 정본 `PublicReportProjection`에는 다음 선택 필드가 추가된다.

| 필드 | 의미와 결속 경계 |
|---|---|
| `citation_groups` | 같은 문서 신원·정규 URL·전체 내용 SHA-256·발표일을 가진 뉴스 출처를 묶어 표시한다. 기존 인용 번호를 모두 정확히 한 번 포함하며 번호·표시 이름·URL·검증 상태·위치·사용 위치를 봉인한다. `Source`·`FactRecord` 원장과 인용 번호를 다시 쓰지 않는다. |
| `reader_notes` | 부분 완성·미완성 상태와 실제 `Source.failed`가 확인된 자료 범위를 안내한다. 자료 수집 실패를 회사가 정보를 제공하지 않았다는 사실로 바꾸지 않으며, SHADOW의 안전 판정만으로 FULL 차단 상태를 추정하지 않는다. |
| `summary_notes` | 요약 항목 번호와 미감사 설명을 연결한다. 구조화된 미감사 연도와 본문이 참조하는 연도·인용 번호가 맞을 때 적용하며, 제목·문장만 보고 미감사 여부를 추정하지 않는다. |

`ReportTable.unaudited_years`도 선택 필드다. 미감사 연도를 구조화해 전달하며, 구형 제목이나 짧은 미감사 문장을 분석해 이 필드를 추정 복원하지 않는다.

## 구형 저장자료와 봉인 보존

위 표시 선택 필드와 `unaudited_years`는 빈 값이면 정본 직렬화에서 생략한다. 필드가 없는 구형 자료는 빈 값으로 읽고 다시 저장할 때도 생략하므로, 필드를 추가했다는 이유만으로 기존 FULL 지문을 바꾸지 않는다.

이미 봉인된 공개 표시 정본이 있는 구형 FULL 보고서는 저장된 정본을 그대로 사용한다. 조회 때 새 출처 묶음·안내를 다시 계산해 끼워 넣거나 기존 제목·claim·짧은 미감사 본문을 재작성하지 않는다. 이 호환 규칙은 구형 자료에 새 품질 검사를 통과한 상태를 부여하거나 기존 봉인 검증을 생략하는 허용이 아니다.
