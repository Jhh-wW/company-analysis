# 출고 전 근거 체크리스트

- 상위 문서: [자료 수집과 근거](./자료_수집과_근거.md)
- 이 문서는 상위 문서 10절의 체크리스트를 그대로 옮긴 것이다. 항목을 줄이거나 순서를 바꾸지 않는다.

- [ ] 회사·법인·연결 범위와 기준일을 확정했는가?
- [ ] 1~8장의 모든 핵심 `FactRecord`가 자사 공시·IR·회사 공식 웹·공식 파트너·규제기관 원문에 결속됐는가?
- [ ] 모든 사실에 원문·페이지·상태가 연결되는가?
- [ ] 실제·잠정·계획·외부 전망을 구분했는가?
- [ ] `fact_status`와 `verification_status`를 별도로 저장했는가?
- [ ] 모든 `state_evidence` 해시가 연결된 `Source.evidence_hashes`에 포함되는가?
- [ ] 근거 재판정을 실행한 경우 모든 인용이 문단 원문의 연속 부분 문자열로 검증되고, 폐기 항목 수와 사유별 개수가 진단에 남았는가?
- [ ] 재판정 조각의 `origin="ai_reclassified"` 표식이 공개 본문에 노출되지 않았는가?
- [ ] 조사자 계산을 재현할 수 있는가?
- [ ] 시장·경쟁 비교의 정의·기간·범위가 같은가?
- [ ] 9장 자기 선언이 회사 주어·닫힌 선언 표지·발표일·공식 출처·exact 해시에 결속되고 우열 판단 없이 투영됐는가?
- [ ] 선택적 비교 후보가 자사 DART 또는 DART 기업개황 attestation을 통과한 자사 공식 HTML IR·공식 웹의 현재형 경쟁 target/list slot·블록·두 해시·seal에 결속됐는가? 발행일·보고기간 없는 IR PDF를 후보에서 제외했는가?
- [ ] v1 저장 형식 읽기 호환 자료도 현재 엄격 문법으로 재검증하고, v2에서 `시장점유율`·과거·잠재·부정·제외·인용·제3자·협력·지원·관계사 경쟁·모호 별칭·`or/또는`를 거부했는가?
- [ ] v2 두 해시가 각각 Source 두 목록과 HMAC seal에 결속되고 exact를 원 HTTP/PDF 바이트 해시로 오해하지 않았는가?
- [ ] `attestation_only`는 내부 Report JSON·저장·감사 등록부에만 있고 공개 웹·PDF·Notion·Markdown에는 후보 원문 citation만 보이는가?
- [ ] 관계만 명시한 후보의 공통 고객·제품/서비스·시장 범위를 양사의 별도 공식 원문으로 증명했는가?
- [ ] 공식 웹·HTML IR 후보가 HTTPS exact host이며 HTTP·인증서 fallback·외부 뉴스·블로그·검색 snippet을 배제했는가?
- [ ] 안정 페이지는 봉인 수집일, 문서형 페이지는 봉인 machine-readable 문서일을 사용하고 `Report.as_of_date` 기준 0~400일인가? 검색 결과를 날짜와 무관하게 제외하고 캐시를 조회 당일 기준으로 재검사했는가?
- [ ] 공식 IR PDF가 최대 2개·문서/사이트 추출 12,000자·사이트 전체 20 MiB와 고정 격리 파서 검사를 통과하고, 수집일을 문서 사실 기준일로 쓰지 않았는가?
- [ ] 수집 상태는 `failed·none·ok`만 쓰고 잘림을 `candidate_scope_complete=False`와 상세 사유로 기록했는가?
- [ ] 실제 재무 비교가 양사 DART의 같은 완료 사업연도·회계 범위를 쓰는가?
- [ ] 공개되지 않은 고객·원가·이익을 추정하지 않았는가?
- [ ] 동일 기준일을 행마다 반복하지 않았는가?
- [ ] 특정 대상의 사실을 상위 제품군·회사 전체로 확대하지 않았는가?
- [ ] 개발·MOU·계약·납품·매출·가동 상태를 정확히 구분했는가?
- [ ] 인과·수익성 문장에 직접 근거가 있는가?
- [ ] 표시 수치가 `ROUND_HALF_UP`으로 재현되는가?
- [ ] 모든 표시 숫자에 결정론적 `numeric_checks`가 있는가?
- [ ] 공개 표가 원 단위와 억원 표시값을 중복 노출하지 않는가?
- [ ] 자료명과 발행처를 원문 표지에서 확인했는가?
- [ ] 제작 메타정보가 완성 보고서 본문에 남지 않았는가?
- [ ] 직무별 업무·KPI·맞춤 지원전략이 포함되지 않았는가?
