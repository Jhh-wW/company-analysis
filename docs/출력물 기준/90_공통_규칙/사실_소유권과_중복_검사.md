# 사실 소유권과 중복 검사 공통 규칙

## 1. 목적

같은 실적·사건·파트너 역할·기준일이 여러 장과 여러 시각물에 반복되는 것을 막는다. 독자가 같은 내용을 다시 읽지 않고, 각 장이 하나의 질문에만 답하도록 모든 사실에 단일 소유 장을 지정한다.

## 2. 사실 식별 단위

하나의 사실은 다음 조합으로 식별한다.

`회사·대상 + 지표 또는 사건 + 기간/시점 + 값 또는 상태`

예:

`A사 + 영업이익률 + 2025년 연결 + 18.9%`

`A사/B파트너 + 해외 유통 계약 + 2025년 현재 + 운영 중`

숫자가 없어도 대상·사건·시점·상태가 같으면 같은 사실이다.

## 3. 단일 소유 원칙

- 모든 사실은 본문 한 장만 소유한다.
- 한 사실은 문장·표·그래프·카드 중 한 형식에서만 완전하게 출력한다.
- 다른 장에서는 숫자·날짜·사례를 복사하지 않고 `결론 + 관련 장`으로 연결한다.
- 핵심 요약은 새 사실을 소유하지 않는다. Writer 검수를 통과한 본문 `FactRecord` 문장을 글자 변경 없이 재사용하고 장 안내만 덧붙인다. 같은 장에서는 숫자 없는 문장을 우선하되 숫자 포함 검증 문장뿐이면 그대로 허용한다.
- 출처 부록은 근거 메타데이터를 소유하며, 본문 내용을 다시 요약하지 않는다.

## 4. 장별 사실 소유권

| 장 | 소유하는 사실 | 소유하지 않는 사실 |
|---|---|---|
| 핵심 요약 | 없음. 본문 `FactRecord` 문장 3~5개의 글자 변경 없는 재사용과 장 안내 | 본문에 없는 수치·날짜·실행 사례, 요약용 재작성 |
| 1. 기업 정체성 | 공식 자기정의, 존재 목적, 산업 내 역할 | 제품별 성과, 수익 구성, 경쟁 평가 |
| 2. 사업 구조와 수익 모델 | 전사 수준의 고객 유형·제공 가치·과금 방식·공통 수익 경로·고객/시장 우선순위 | 제품별 최신 실행·포트폴리오 역할 |
| 3. 핵심 제품·서비스 | 제품별 현재 실행 근거·분석 단계·포트폴리오 역할. 고객·시장·수익은 2장의 분류명만 참조 | 전사 수익 구조·고객/시장 우선순위의 재설명, 전사 3개년 실적, 미실행 계획, 파트너 계약 |
| 4. 3개년 변화 `#과거` | 최근 3년 전사 실적과 완료된 실행·확인된 결과 | 현재 미해결 문제, 미래 계획 |
| 5. 당면 과제 `#현재` | 현재 미해결 문제, 최신 문제 수치, 진행 중 대응 | 완료된 실행, 미실행 계획 |
| 6. 성장 전략 `#미래` | 공식 목표·계획·예정·향후 일정 | 완료된 성과, 현재 대응 수치 |
| 7. 사업 운영과 파트너 | 운영 기반, 파트너 역할, 확인된 관계 범위 | 경쟁우위 평가, 고객 역할의 반복 |
| 8. 인재상과 일하는 방식 | 공식 인재상·전사 공통 가치와 공식 자료에서 확인된 조직 사례(적용 범위 포함) | 직무별 업무·KPI·맞춤 지원전략, 조직 사례의 전사 일반화 |
| 9. 동종업계 비교 결과 `(조건부)` | 같은 조건의 비교 결과·사업 의미·비교 한계 | 자사 실적 원문의 재출력 |
| 부록 | 문서명·발행일·페이지·허용된 공식 자료 유형·사실/검증 상태 | 본문 분석의 반복 요약, canonical 런타임에서 생략한 외부 분석·뉴스 |

## 5. 중복으로 판정하는 경우

- 같은 수치와 기간을 문장과 표에 각각 씀
- 같은 실적 수치를 4장, 5장, 9장에 반복함
- 같은 제품 출시·투어·증설·계약 사례를 여러 장에서 다시 설명함
- 같은 파트너의 역할을 2장과 7장에서 되풀이함
- 같은 포트폴리오 단계와 근거를 카드와 표에 모두 씀
- 모든 표 행에 같은 기준일·출처·상태 문구를 반복함
- 단어를 바꾸었어도 대상·사건·시점·값이 같음

## 6. 중복이 아닌 경우

- 같은 핵심 용어를 서로 다른 질문에 필요한 최소 범위로 사용함
- 같은 지표라도 기간 또는 범위가 다르고 변화 비교에 반드시 필요함
- 본문 사실과 부록의 출처 메타데이터가 연결됨
- 페이지 머리글·바닥글의 회사명·보고서 기준일처럼 문서 탐색용 고정 요소
- 다른 장에서 수치를 복사하지 않고 `이익 전환 과제는 계속된다(5장)`처럼 결론만 참조함

단, 중복이 아니더라도 한 장의 사실 소유권을 침해하면 이동한다.

## 7. 기준일·출처 반복 방지

- 보고서 전체 기준일은 표지에 한 번 명확히 제시한다.
- 포트폴리오 표처럼 모든 행의 자료 시점이 같으면 표 위에 `자료 기준: YYYY.MM.DD`를 한 번만 쓴다.
- 행마다 `2026년 2분기 기준`, `[4]`, `현재`를 반복하지 않는다.
- 특정 행의 시점이나 상태만 다르고 해석에 영향을 줄 때 그 행에만 예외를 적는다.
- 출처 번호가 동일한 여러 행은 표 제목·주석에 한 번 연결할 수 있다. 서로 다른 근거가 꼭 필요할 때만 행별 번호를 둔다.
- 부록의 발행일은 검증 메타데이터이므로 본문 날짜 반복과 별도로 허용한다.

## 8. 작성 단계의 소유권 지정 절차

1. 조사 메모의 모든 주장에 `fact_id`를 부여하고 저장·캐시·렌더링 전 과정에서 같은 ID를 유지한다.
2. 각 사실이 답하는 질문에 따라 소유 장을 하나 지정한다.
3. 먼저 소유 장에 가장 이해하기 쉬운 형식 하나로 배치한다.
4. 다른 장에서 필요하면 숫자·날짜·사례를 제거한 참조 결론만 쓴다.
5. 시각화와 본문이 같은 사실을 보여주면 시각화 안에만 값을 두고 본문은 의미만 쓴다.
6. 완성 초안의 모든 숫자·백분율·날짜·고유 사건·파트너 역할을 검색한다.
7. 두 번 이상 발견된 항목을 `허용 참조·메타데이터·실제 중복`으로 분류한다.
8. 실제 중복은 소유 장만 남기고 나머지를 삭제하거나 장 참조로 바꾼다.

## 9. 충돌 해결 순서

같은 사실이 여러 장에 필요해 보이면 다음 순서로 판단한다.

1. 가장 직접적으로 답하는 장이 소유한다.
2. 시간 상태가 있는 사실은 `완료=4장`, `미해결/대응 중=5장`, `미실행 계획=6장`을 우선한다.
3. 제품 자체의 최근 실행은 3장, 전사 전체의 결과 변화는 4장이 소유한다.
4. 파트너 관계의 존재와 역할은 7장, 그 구조가 경쟁사와 다른지에 대한 비교만 9장이 소유한다.
5. 9장은 자사 수치를 복사하지 않고 1~8장의 해당 장을 참조한다. 비교사 수치만 같은 표에 새로 제시할 수 있다.

## 10. 장 간 참조 문장

값을 되풀이하지 않고 다음처럼 연결한다.

- `수익 구조의 중심은 2장에서 확인할 수 있다.`
- `관련 현재 과제는 5장 참조.`
- `해당 파트너의 운영 역할은 7장 참조.`
- `자사 수익성 수치는 4장 참조.`

`앞서 본 것처럼`처럼 위치가 불명확한 표현은 쓰지 않는다.

## 11. 출력 중단 게이트

다음 중 하나라도 발생하면 PDF 출력을 중단한다.

- 같은 `회사·대상 + 지표/사건 + 기간 + 값/상태`가 본문에서 두 번 이상 발견됨
- 같은 값을 카드와 표 또는 그래프에 동시에 사용함
- 요약 문장이 결속된 본문 `FactRecord`와 다르거나 본문에 없는 수치·날짜·사례를 추가함
- 같은 파트너 역할을 여러 장에서 설명함
- 포트폴리오 표의 모든 행에 동일 기준일·출처 문구가 반복됨
- 장별 사실 소유권을 정하지 못한 주장이 남음

## 12. 출고 전 체크리스트

- [ ] 모든 사실에 하나의 `fact_id`와 소유 장이 있는가?
- [ ] 같은 수치·날짜·사건·파트너 역할을 전체 검색했는가?
- [ ] 문장·카드·표·그래프 사이의 이중 출력을 제거했는가?
- [ ] 요약이 Writer 검수 완료 본문 문장과 글자 단위로 같고 `verified_fact_reuse`로 결속됐는가?
- [ ] 다른 장의 사실은 결론과 장 참조로만 연결했는가?
- [ ] `#과거·#현재·#미래`의 시간 상태가 섞이지 않았는가?
- [ ] 공통 기준일·출처는 표 위에 한 번만 표시했는가?
- [ ] 9장이 자사 사실을 다시 출력하지 않는가?
- [ ] 직무별 업무·KPI·맞춤 지원전략이 포함되지 않았는가?
- [ ] 중복이 남아 있으면 출력을 중단했는가?

## 짧은 범용 예시

잘못된 출력:

> 4장: 2025년 영업이익률은 18.9%다.
> 5장: 2025년 영업이익률 18.9%로 수익성이 낮아졌다.
> 9장: 영업이익률 18.9%는 경쟁사보다 높다.

수정된 출력:

> 4장에 자사 수치와 변화를 한 번만 둔다. 5장은 현재 해결 중인 원인과 대응만 쓰고, 9장은 `자사 수익성은 4장 참조`라고 연결한 뒤 같은 기준의 비교사 근거만 제시한다.
