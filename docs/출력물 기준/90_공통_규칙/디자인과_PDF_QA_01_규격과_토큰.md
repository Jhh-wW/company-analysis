> 챕터: 01. 문서 규격·색상·서체·위계·여백 (본문 §1~§5)

## 1. 문서 규격

- 용지: A4 세로, 210 × 297mm
- 기본 여백: 왼쪽 17mm, 오른쪽 17mm, 위 18mm, 아래 16mm
- 본문 폭: 약 176mm
- 표지 제목: `[회사명]` 줄바꿈 후 `분석 보고서`. 제목에 `기업`을 넣지 않는다.
- 표지 제목 블록은 첫 장의 세로 중앙보다 약간 위인 `상단에서 72~118mm` 영역에 둔다. 좌우 기본 여백 안에서 왼쪽 정렬하며, 페이지 맨 위에 붙이지 않는다.
- 표지 메타정보는 제목 바로 아래에 한 줄로 둔다. 회사 로고·영문 회사명·설명용 부제는 별도로 반복하지 않는다.
- 표지 `핵심 요약`은 첫 장 하단의 `상단에서 190~262mm` 영역에 고정한다.
- 표지 `최신 사업연도 실적` 띠는 제목 블록과 핵심 요약 사이의 `상단에서 138~166mm` 영역에 둔다. 띠를 낼 값이 없는 보고서에서는 같은 자리를 예전처럼 의도된 표지 여백으로 유지한다(빈 제목·빈 칸을 남기지 않는다).
- 2쪽 이후 상단: 22pt 검은 띠. 왼쪽 `[회사명] 분석 보고서`, 오른쪽 `현재 장 이름 · 기준일 YYYY.MM.DD`. 현재 장은 그 페이지의 첫 장 제목을 따르며 알 수 없으면 장 이름만 비운다.
- 2쪽 이후 하단: 왼쪽 회사명 / 오른쪽 페이지 번호
- 페이지 번호는 표지를 1쪽으로 계산하되 표지에는 표시하지 않는다.
- 모든 페이지의 제목·작성자·주제 PDF 메타데이터를 채운다.
- 최종 파일명은 회사가 바뀌어도 동일한 규칙을 쓴다. 예: `<company-slug>-company-analysis.pdf`.

## 2. 색상

### 디자인 토큰 v1

| 토큰 | 값 | 용도 |
|---|---|---|
| `ink` | `#111111` | 제목·표지 배경·번호 배지·표 머리행 |
| `grey-6` | `#666666` | 본문 보조 글자 |
| `grey-4` | `#999999` | 캡션·축 이름·약한 보조 글자 |
| `grey-2` | `#CCCCCC` | 0.5pt 구분선·표 안쪽 선·카드 테두리 |
| `grey-1` | `#F5F5F5` | 표 왼쪽 라벨 열·옅은 카드 배경 |
| `white` | `#FFFFFF` | 종이·표 본문·검은 면 위 글자 |
| 차트 5단계 | `#B3B3B3` → `#8C8C8C` → `#666666` → `#444444` → `#222222` | 흐름·막대·구성 도식의 밝은 단계→어두운 단계 |
| 예외 경고 | `#E7000B` | 손실·하락·오류처럼 의미가 명확한 위험 |

- 기본은 검정·회색·흰색만 사용한다.
- 빨간색은 손실·하락·오류처럼 의미가 명확한 예외에만 쓴다.
- 장마다 다른 강조색을 배정하지 않는다.
- 상태를 색만으로 구분하지 않고 텍스트를 함께 쓴다.
- 표 머리글은 `ink` 배경과 흰 SemiBold 글자를 사용한다.
- 회사 로고 색·브랜드 색을 보고서 전체 테마로 사용하지 않는다.

## 3. 서체와 글자 크기

### 서체

- 기본: Freesentation Regular
- 강조: Freesentation SemiBold
- PDF에는 사용 글꼴을 임베드한다.
- 한글·영문·숫자에 같은 계열을 사용한다.
- 회사 로고 서체·장식용 영문 세리프를 본문에 섞지 않는다.
- 대체 글꼴이 필요하면 `맑은 고딕`을 사용하되 최종 출력 전 줄바꿈을 다시 검수한다.

### 권장 크기

| 요소 | 크기·행간 |
|---|---|
| 표지 회사명·보고서명 | 34pt SemiBold / 39pt |
| 장 제목 | 20pt Regular / 24pt |
| 장 번호 배지 | 9pt SemiBold / 18×18pt 검은 네모 |
| 소제목 | 11pt / 14pt |
| 강조 결론 | 13~14pt / 18~20pt |
| 본문 | 9.2~9.6pt / 13.8~14.4pt |
| 카드 본문 | 8.2~8.6pt / 11.5~12pt |
| 표 머리글·셀 | 7.5~7.8pt / 9.5~10.2pt |
| 주석·출처 보조문 | 6.9~7.7pt / 9.2~10.8pt |
| 상단 띠 | 8pt 흰색 / 높이 22pt |
| 하단 메타정보 | 6.6~6.8pt |

- 본문을 페이지에 맞추기 위해 9pt 아래로 줄이지 않는다.
- 일반 표를 7.4pt 아래로 줄이지 않는다. 출처표도 6.9pt 아래로 줄이지 않는다.
- 6.5pt 미만 글자는 어떤 경우에도 허용하지 않는다.
- 글자가 넘치면 폰트를 줄이기보다 문장을 줄이고 표를 나누거나 다음 페이지로 보낸다.
- 숫자는 가능한 한 tabular 숫자 정렬을 사용한다.

## 4. 제목과 정보 위계

- 표지는 `[회사명]`을 먼저 쓰고 다음 줄에 `분석 보고서`를 쓴다. `기업분석 보고서`, `회사 분석 보고서`처럼 중간에 다른 말을 더하지 않는다.
- `취업 준비를 위한`, `회사 공식 자료 우선` 같은 설명 문구는 표지에서 제거한다.
- 장 제목은 `번호. 제목` 글자 순서를 유지하되 번호를 18×18pt 검은 네모 배지 안의 흰 9pt SemiBold로 표시한다. 제목은 20pt Regular이며, 부록 배지는 폭만 넓혀 `부록`을 그대로 쓴다.
- `#과거`, `#현재`, `#미래` 태그는 4·5·6장 제목 옆에만 회색 작은 글자로 쓴다.
- 다른 장에는 상태 배지나 `운영 중` 같은 장식 태그를 붙이지 않는다.
- 소제목은 `무엇을 파나` 같은 구어체 대신 `주요 제품·서비스`, `최근 실행 근거`, `수익 창출 구조`, `포트폴리오 역할`처럼 공식 문서형 명칭을 쓴다.
- 소제목은 SemiBold로 본문과 명확히 구분한다.
- 장 도입문은 핵심 결론 한두 문장으로 시작한다. `이 장에서는 …을 정리했다` 같은 제작 설명은 쓰지 않는다.

## 5. 여백과 간격

- 큰 제목 뒤: 7~10pt + 구분선 + 9~12pt
- 문단 사이: 4~8pt
- 소제목 위: 12~16pt, 아래: 4~7pt
- 표·그래프 위아래: 10~16pt
- 카드 사이: 4~6mm
- 표 셀 안쪽: 좌우 4~7pt, 위아래 4~7pt
- 한 페이지 안에서 같은 계층은 같은 간격을 유지한다.
- 빽빽함을 해결하기 위해 임의로 자간·장평을 줄이지 않는다.
- 장 제목이 페이지 하단 25mm 이내에서 혼자 시작하지 않게 한다.
