# 보고서 근거·내용 품질 개선 — 검증 중

이 문서는 2026-09-27 작업의 변경 이유와 남은 검증을 설명한다. 실제 회사명·기사 원문·운영 실행 ID·개인정보·비밀값은 기록하지 않는다. **유료 최종 검증과 운영 배포가 끝났다는 뜻이 아니다.**

## 원인과 조치

뉴스는 검색 후보가 많아도 기사 본문을 충분히 읽지 못하고 회사 관련성 검증을 통과한 근거가 없으면 작성 단계에 전달되지 않는다. 따라서 검색 건수만 늘리거나 PDF에 뉴스 칸을 강제로 채우는 방식은 사실성을 해친다. 이번 변경은 접근 거절이 확정된 기사에 한해 미시도 후보를 제한적으로 보충 조사하고, 본문에 대상 법인의 허용된 이름이 전혀 없으면 AI 호출 전에 제외한다. 본문 검색·출처 선별·신원 결속·인용 기준 자체는 완화하지 않는다. 발행처·기자·저작권 표기의 회사명과 기사 본문이 다루는 법인을 구별하는 지침도 보강했다.

뉴스 수집 정책 버전을 v8로 올려 이전 검색 스냅샷을 새 판정과 혼용하지 않는다. 선제 이름 필터에 걸린 기사는 “다른 회사로 확정”이 아니라 “본문 신원 미확인”으로 남는다. 이 선택은 검증 가능한 기사에 AI 예산을 쓰는 이점이 있지만, 과거에는 AI가 타사로 확정해 캐시에 재사용할 수 있었던 일부 후보도 재조사하게 되어 캐시 적중률과 비용에 불리할 수 있다. 접근 거절 보충 시도도 남은 기사·본문 호출·시간·분석 예산의 범위에서만 허용하고, 진단에 기본 시도와 대체 시도를 분리해 남긴다.

1·2장의 내용이 회사 사업 사실 대신 공사 진행률·원가 측정·기간별 수익배분이라는 일반 회계방법으로 채워질 수 있는 문형을 좁게 탐지한다. 새 규칙은 해당 두 장에만 적용하며, 금액·명명된 실제 계약·고객사 서비스 제공·정책 변경·실제 완료 사건과 혼합된 항목을 통째로 삭제하지 않는다. 수익원 구성과 인식 조건을 서로 다른 인용에서 이어 붙여 자기 인용 면제를 얻던 경계도 닫았다. 일반론의 일부가 실제 사업 설명과 한 항목에 섞이면 가드는 혼합으로 관측할 뿐 삭제하지 않으므로, 최종 산출물 검수는 여전히 필요하다. 4장의 실제 공사완료·누적 실적은 이 새 규칙으로 무차별 제거하지 않는다.

4장 추세 그래프는 검증된 완료 사업연도가 두 개여도 세 개년과 같은 막대그래프를 쓴다. 실제 두 연도·원값·단위·출처만 유지하고 빈 연도나 값을 만들지 않는다. 1개년은 원표이고, 매출 구성·관계도·흐름도의 각각 다른 허용 조건은 바꾸지 않았다. 2개년 그림은 3개년 자료를 확보했다는 뜻도, FULL 품질 계약을 충족했다는 뜻도 아니다.

## 장별 형식 원칙

| 장 | 근거가 있을 때의 주 표현 | 근거가 부족할 때 |
|---|---|---|
| 1 정체성 | 공식 자기정의·사업 범위 카드 | 사실 문장만 남기고 회계 일반론은 배제 |
| 2 사업·수익 모델 | 검증된 흐름도와 구성비 그래프 | 관계가 불명확하면 원표·문장 |
| 3 제품·서비스 | 역할 카드와 검증된 구성비 | 이름만으로 역할을 지어내지 않음 |
| 4 변화·실적 | 비교 가능한 2~6개 완료 기간의 추세 막대 | 한 시점·비수치면 원표, 수치 없으면 그래프 없음 |
| 5 과제·대응 | 검증된 과제·대응 짝의 관계도 | 짝이 불충분하면 원표 또는 장 생략 |
| 6 성장 전략 | 공식 계획·시점 카드 | 계획을 완료 성과로 바꾸지 않음 |
| 7 운영·파트너 | 실제 연속 단계의 흐름도 | 관계가 끊기면 카드·원표 |
| 8 문화·인재 | 공식 가치·사례 카드 | 확인 자료가 없으면 장 생략 |
| 9 비교 | 기준과 한계를 밝힌 문장·표 | 비교 근거가 없으면 장 생략 |

형식의 일관성은 모든 장에 그림을 넣는다는 뜻이 아니다. 같은 장의 같은 종류 자료에 같은 선택 기준을 적용하면서, 자료가 모자라면 숫자와 인용을 보존한 원표·문장으로 되돌아간다.

## 기존 경로와의 구분

2026-09-18 실행에서 나타난 재판정 AI 소유권·캐시 미스 문제는 2026-09-22 별도 패치로 이미 수정됐다. 그 과거 실행을 현재 뉴스 누락의 재발 증거로 취급하지 않는다. 반대로 당시의 부분 보고서 허용 정책은 수집 실패와 실제 자료 부족을 동일하게 보이게 할 수 있었다. 이번 조치는 그 사실성 경계와 뉴스 수집 실패를 분리해 살피는 작업이며, 부족한 장을 근거 없이 채워 FULL로 승격시키지 않는다.

## 현재 검증과 남은 결정

합성 자료 회귀에서 2개년 추세의 웹·PDF 공통 표시, 음수·기간·원값 보존과 회계 가드의 정상 거래 보존을 확인했다. 과거 저장된 2개년 보고서를 로컬에서 무료 재렌더한 결과, 기존 PDF와 새 PDF의 공개 내용 지문은 같고 세 지표가 각각 두 연도의 막대로 표시됐다. 그래프 묶음의 페이지 이동으로 쪽수는 한 쪽 늘어나는 레이아웃 상충이 있어 최종 PDF 시각 검수를 계속한다. 과거 승인·배포된 PDF 파일은 변경하지 않았다.

전체 앱 회귀, 독립 품질 검토, 실제 유료 보고서의 뉴스 근거·장별 밀도·PDF 시각 검증과 운영 배포 확인은 별도 최종 관문이다. 이 관문을 통과하기 전에는 “문제가 해결됐다”거나 “서비스가 정상화됐다”고 선언하지 않는다.
