# ADR 0001 — 기능 중심 구조를 점진적으로 적용한다

## 상태

승인됨 — 2026-08-17

## 맥락

이 저장소에는 함께 배포되는 두 코드 영역이 필요합니다.

- `app/`은 로그인, 접근 제한, 화면, 저장, 보고서 내보내기와 배포를 담당합니다.
- `analysis_engine/`은 실제 조사 경험으로 검증된 엔진과 데모 자료를 담습니다. 현재
  `app/src/features/pipeline/real.py`와 Docker 이미지가 직접 사용하므로 실행
  의존성입니다.

두 영역의 `src/features/`는 이미 기능별 로직과 시험을 가까이 둡니다. 다만 현재
서비스에는 기능끼리 직접 가져오는 기존 코드가 있습니다. 첫 배포 직전에 이것을
한꺼번에 금지하면 많은 파일과 경로를 옮겨야 하고, 폴더 정리보다 실행 안정성에 더
큰 위험을 만듭니다.

## 결정

### 1. `app/`과 `analysis_engine/`을 당분간 함께 유지한다

둘은 별도 서비스가 아니라 하나의 배포 이미지 안에서 서로 다른 역할을 맡습니다.

- `app/`: 사용자가 접하는 운영 서비스
- `analysis_engine/`: 실제 조사 엔진과 기존 동작의 기준

`analysis_engine` 기능은 동일 동작 시험을 갖춘 작은 단위로 개선합니다. Docker,
실행 코드와 시험에서 더 이상 참조하지 않을 때만 분리하거나 삭제할 수 있습니다.

### 2. 폴더 경계를 다음처럼 해석한다

| 경계 | 책임 |
|---|---|
| `features/<name>/` | 기능 하나의 로직, 상수, 전용 자료와 시험 |
| `core/` | 경로·공통 형식처럼 여러 기능이 실제로 함께 쓰는 얇은 기반 |
| `web/` | HTTP 요청·응답, 화면, 라우팅과 기능 조립 |
| `features/pipeline/` | 화면과 조사 엔진 사이의 조립 경계 |
| `pipeline/port.py` | 화면·데모·실조사가 공유하는 입력·출력 계약 |
| `pipeline/demo.py` | 비용 없이 저장 자료를 재생하는 구현 |
| `pipeline/real.py` | 실제 조사 엔진과 현재 기능들을 연결하는 구현 |

`core/`에는 특정 기능만을 위한 규칙을 넣지 않습니다. 두 기능 이상이 실제로
공유할 때만 공통 코드로 올립니다. `web/`은 조사 엔진 파일을 직접 부르지 않고
`pipeline` 계약을 거칩니다.

### 3. 기존 직접 import는 즉시 전면 금지하지 않는다

현재 직접 import는 첫 배포 동작을 보존하기 위한 기존 예외로 둡니다. 특히 `web`과
`pipeline`은 여러 기능을 조립하는 자리이므로 필요한 의존을 가집니다. 지금
import-linter를 오류 모드로 켜면 구조 개선이 아니라 대규모 이동 작업이 됩니다.

대신 새 코드부터 다음 원칙을 적용합니다.

- 기능 로직은 다른 기능의 내부 파일을 새로 직접 참조하지 않습니다.
- 기능 간 자료 교환은 작은 공개 계약(`port.py` 등)을 우선합니다.
- `core/`를 모든 것을 넣는 공용 창고로 만들지 않습니다.
- `core`와 개별 기능은 `web`을 참조하지 않습니다.
- `web`과 `pipeline`이 기능들을 조립합니다.
- 기존 직접 의존은 관련 기능을 수정할 때 시험과 함께 한 건씩 줄입니다.

공개 계약과 허용 예외가 정리되면 import-linter를 먼저 점검용으로 연결하고,
위반 목록을 없앤 다음 CI 차단 규칙으로 전환합니다.

### 4. 새 기능은 작게 시작한다

새 기능은 `features/<name>/` 아래 최소한의 로직과 시험만 만듭니다. 필요하지 않은
빈 하위 폴더는 만들지 않습니다. 기능이 커지면 그 폴더 안에서 파일을 나누며,
기능 경계를 새로 정할 때는 ADR을 추가합니다.

## 결과

- 첫 배포의 검증된 동작을 보존하면서 GitHub에서 역할이 읽히는 구조를 갖춥니다.
- 기능 수정 시 관련 코드와 시험을 같은 폴더에서 찾기 쉬워집니다.
- 당분간 두 코드 영역과 일부 직접 의존을 관리해야 합니다.
- 구조 개선은 한 번의 대규모 이동이 아니라 계약 시험을 동반한 작은 이전으로
  진행합니다.
