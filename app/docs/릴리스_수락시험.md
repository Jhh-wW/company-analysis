# 릴리스 수락시험

이 도구는 운영 DB나 기존 로컬 데모 자료를 열지 않는다. `app/` 아래에 임시 실행
폴더를 만들고 그 안의 SQLite·관측 기록만 사용하는 무료 `PIPELINE=demo` 서버를
두 번 기동한 뒤 자동으로 종료·삭제한다. 부모 프로세스의 provider 자격 증명은 읽지
않고 자식 환경에서도 제외하며, 외부 HTTP 프록시는 닫힌 loopback 주소로 고정한다.

## 한 명령 실행

저장소 루트의 전용 가상환경을 준비한 뒤 `app/`에서 실행한다.

```powershell
..\.venv\Scripts\python.exe -m src.features.release_acceptance
```

출력은 기계 판독용 JSON과 한국어 요약을 연이어 낸다. 종료 코드는 `PASS=0`,
`FAIL=1`, `BLOCKED=2`다.

검사 범위는 서버 기동·종료, `/healthz`, `/readyz`, 로컬 관리자 인증과 관리자
권한·CSRF, 무료 데모 한 건, 같은 실행 토큰 재사용 차단, SQLite 비용 0원과 중복
불변식, 결과 화면·PDF·초대 링크의 동일 `report_id`, 같은 DB로 재시작한 저장본,
민감 marker 비노출, 마지막 loopback 포트 회수다.

의존성 누락처럼 시험 환경이 준비되지 않았거나 선행 단계가 실패해 실제 관측할 수 없는
항목은 합격으로 간주하지 않고 `BLOCKED`로 남긴다. 예상 응답과 다른 실제 동작,
민감 marker 노출, 비용 증가, 포트 잔류는 `FAIL`이다. PDF 자동출고 게이트가 멈춘
경우에도 부분 성공으로 바꾸지 않는다.
