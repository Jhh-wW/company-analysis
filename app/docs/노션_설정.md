# 노션으로 보내기 설정 안내

**결론:** ① 노션에서 「통합」을 하나 만들어 **토큰(비밀 열쇠)**을 받고,
② 보고서를 넣어둘 **페이지를 하나 만들어** 그 통합을 **「연결」**해 준 다음,
③ `서버켜기.ps1`을 실행할 때 물어보는 자리에 붙여넣으면 끝입니다.

**약 5분** 걸립니다. 개발 지식이 없어도 따라 할 수 있게 썼습니다.

> **먼저 알아두실 것 3가지**
> - **통합(integration)** = 「이 프로그램이 내 노션에 글을 쓸 수 있게 허락하는 출입증」입니다.
> - ★ **가장 흔한 실수는 ②번(페이지에 연결 추가)을 빼먹는 것**입니다.
>   토큰이 맞아도 이걸 안 하면 **「찾을 수 없음(404)」**이 뜹니다.
>   출입증만 만들고 **어느 방에 들어갈지 안 정해준** 상태이기 때문입니다.
> - ★★ **노션 보내기는 «관리자 전용»입니다** (기획서 D10 규칙).
>   서버를 켤 때 **구글 로그인도 반드시 `y`로 켜고 로그인까지 해야** 버튼이 보입니다.
>   안 켜면 토큰이 멀쩡해도 **[노션으로 보내기] 버튼 자체가 안 나타납니다.**
>   구글 로그인 설정은 [구글로그인_설정.md](구글로그인_설정.md)를 보세요.

---

## 1단계 — 통합 만들고 토큰 받기

1. 브라우저에서 **https://www.notion.so/my-integrations** 을 엽니다.
   (노션에 로그인돼 있어야 합니다)

2. **[새 API 통합]** 또는 **[+ New integration]** 버튼을 누릅니다.

3. 칸을 채웁니다.

   | 칸 | 넣을 것 |
   |---|---|
   | 이름 (Name) | `기업분석` — 아무 이름이나 됩니다. 나중에 알아보기 쉬운 걸로 |
   | 연결된 워크스페이스 | **보고서를 저장할 워크스페이스**를 고릅니다 (아래 ⚠️ 참고) |
   | 유형 (Type) | **내부(Internal)** 그대로 둡니다 |

   ⚠️ **워크스페이스를 잘 고르세요.** 노션 계정이 여러 개거나 워크스페이스가
   여러 개면, 여기서 고른 곳에만 글을 쓸 수 있습니다. 나중에 바꾸려면 통합을
   새로 만들어야 합니다.

4. **[저장]** 또는 **[Submit]** 을 누릅니다.

5. 다음 화면에서 **「내부 통합 시크릿(Internal Integration Secret)」** 을 찾아
   **[표시]** → **[복사]** 를 누릅니다.

   - `ntn_` 또는 `secret_` 으로 시작하는 긴 글자입니다.
   - ★ **이건 비밀번호와 같습니다.** 카톡·메일로 남에게 보내지 마세요.
   - 지금 **메모장에 잠깐 붙여넣어** 두세요. 3단계에서 씁니다.

---

## 2단계 — 페이지 만들고 «연결 추가» ★ 여기가 핵심

1. 노션에서 **새 페이지**를 하나 만듭니다.
   제목은 `기업분석 보고서` 처럼 아무거나 됩니다.
   → 조사한 보고서들이 **이 페이지 «안에»** 하나씩 쌓입니다.

2. 그 페이지 **오른쪽 위 `···`** 을 누릅니다.

3. **[연결]** 또는 **[연결 추가 / Add connections]** 를 찾아 누릅니다.
   - 메뉴 아래쪽에 있습니다. 안 보이면 스크롤을 내려보세요.

4. 1단계에서 만든 이름(`기업분석`)을 찾아 누릅니다.

5. **[확인]** 또는 **[Confirm]** 을 누릅니다.

> ✅ **제대로 됐는지 확인하는 법**: 그 페이지의 `···` → **[연결]** 을 다시 눌렀을 때
> `기업분석`이 목록에 **남아 있으면** 된 겁니다.

---

## 3단계 — 페이지 주소 복사

같은 페이지에서 **오른쪽 위 `···` → [링크 복사]** 를 누릅니다.

`https://www.notion.so/...` 로 시작하는 주소가 복사됩니다.
**주소를 통째로** 쓰면 됩니다 — 프로그램이 필요한 부분만 알아서 골라냅니다.

---

## 4단계 — 서버 켤 때 붙여넣기

PowerShell에서 평소처럼 켭니다.

```powershell
cd "C:\프로젝트를_받은_폴더\기업분석2\app"
.\서버켜기.ps1
```

물어보는 순서대로 답합니다.

| 물어보는 것 | 답 |
|---|---|
| 구글 로그인을 켤까요? | **`y`** ← ★ **반드시.** `n`이면 노션 버튼이 안 보입니다 |
| 클라이언트 ID · 보안 비밀 | 구글 클라우드 콘솔에서 받은 값 |
| **노션으로 보내기를 켤까요?** | **`y`** |
| **노션 토큰** | 1단계에서 복사한 것 붙여넣기 (**마우스 오른쪽 클릭**) |
| **페이지 주소** | 3단계에서 복사한 주소 붙여넣기 |
| 어떤 방식으로 돌릴까요? | 평소대로 (`1` = 데모) |

> **토큰을 붙여넣어도 화면에 아무것도 안 보입니다.** 고장이 아니라
> **일부러 안 보이게** 한 것입니다(어깨너머로 보이거나 캡처에 찍히지 않게).
> 그냥 붙여넣고 엔터를 누르세요.

`노션 설정 완료 (페이지 ...)` 라고 초록색으로 뜨면 된 겁니다.

---

## 5단계 — 실제로 보내보기

1. 브라우저에서 `http://localhost:8000` → **오른쪽 위 [구글로 로그인]** ← ★ 먼저
2. 회사 하나 조사
3. 보고서 화면 아래 **[노션으로 보내기]** 를 누릅니다
4. 노션에서 2단계의 페이지를 열어 **안에 새 페이지가 생겼는지** 확인합니다

> **버튼이 안 보이면 로그인이 안 된 것입니다.** 그 자리에 대신
> 「노션 보내기는 **관리자만** 쓸 수 있습니다」라고 적혀 있습니다.

## 안 될 때

| 증상 | 원인 | 할 일 |
|---|---|---|
| **[노션으로 보내기] 버튼이 아예 없다** | ★ **구글 로그인을 안 켰거나 로그인을 안 했다** — 노션 보내기는 관리자 전용 | 서버를 껐다(`Ctrl+C`) 켜서 구글 로그인 `y` → 화면 오른쪽 위에서 로그인 |
| **「찾을 수 없음」 / 404** | ★ **2단계(연결 추가)를 빠뜨렸다** — 압도적으로 흔합니다 | 페이지 `···` → [연결] 에 통합이 있는지 확인 |
| 404인데 연결도 했다 | 통합을 **다른 워크스페이스**에 만들었다 | 1단계를 그 워크스페이스로 다시 |
| **「권한 없음」 / 401** | 토큰이 틀렸거나 잘릴 때 일부만 복사됐다 | 1단계에서 **[복사] 버튼**으로 다시 복사 |
| 버튼을 눌러도 반응이 없다 | 서버를 켤 때 노션을 `n`으로 답했다 | 서버를 껐다(`Ctrl+C`) 다시 켜고 `y` |
| 주소를 못 읽었다고 나온다 | 페이지 주소가 아닌 걸 붙여넣었다 | `···` → **[링크 복사]** 로 다시 |

## 자주 묻는 것

**Q. 서버를 끄면 매번 다시 넣어야 하나요?**
**아니요.** 4단계 마지막에 **「이 컴퓨터에 기억시킬까요?」** 라고 물어봅니다.
**`y`** 라고 답하면 **다음부터는 아무것도 안 물어봅니다.**

다음번에 `.\서버켜기.ps1`을 실행하면 이렇게 나옵니다:

```
이 컴퓨터에 저장된 설정이 있습니다:
  · 구글 로그인 (클라이언트 ID·보안 비밀)
  · 노션 보내기 (토큰·페이지)

  y = 그대로 쓴다 (아무것도 안 물어봅니다)
  n = 이번만 새로 입력한다
  d = 저장된 것을 «지운다»
```

**`y`** 만 누르면 바로 서버가 켜집니다.

**Q. 어디에 저장되나요? 안전한가요?**
윈도우의 **「사용자 환경 변수」** 에 저장됩니다 — **프로젝트 폴더가 아닙니다.**
그래서 실수로 **깃(코드 저장소)에 올라가거나 파일째 남에게 보내질 위험이 없습니다.**

⚠️ 다만 **이 컴퓨터를 쓰는 다른 사람은 읽을 수 있습니다.**
공용 PC에서는 **`n`** 으로 답해 이번만 쓰세요.

**Q. 저장한 걸 지우려면?**
`.\서버켜기.ps1` 실행 → 첫 질문에 **`d`**. 한 번에 다 지워집니다.

**Q. 토큰이 새어나간 것 같아요.**
https://www.notion.so/my-integrations → 해당 통합 → **[시크릿 재생성]**.
옛 토큰은 즉시 못 쓰게 됩니다.

**Q. 노션을 안 쓰면 문제가 되나요?**
아니요. **[워드로 내려받기]는 그대로** 됩니다. 노션은 선택 기능입니다.
